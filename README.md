# Labour Junction

A Flutter-based mobile application developed to connect daily wage workers and service providers with customers seeking reliable services.

Labour Junction helps workers such as plumbers, electricians, painters, caterers, and other skilled professionals showcase their services and connect with potential customers through a simple and user-friendly platform.

## Problem Statement

Many skilled workers struggle to find customers consistently, while customers often face difficulties finding trusted service providers. Labour Junction aims to bridge this gap by providing a digital platform that connects both parties efficiently.

## Features

* User Registration and Login
* Worker Profile Management
* Service Category Selection
* Customer and Worker Connectivity
* Firebase Authentication
* Cloud Firestore Database
* Responsive Flutter UI
* Cross-Platform Support
